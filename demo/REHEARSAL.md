# 操作デモの検証

Stageshowのclose-upを出発点に、単一ウィンドウ、測定したカーソルの操作対象、結果を残す一回再生を使用。設定トグルを、Lean宣言の選択・依存の強調・Markdownプレビューに置き換えた。比較用の元例は `reference/` にある。

- 横長: 1040×600のステージ。スマートフォン: 358×500の専用構成。
- 実在のサンプルに由来する宣言名を使い、主張の表記は説明用に簡略化。
- 動画は実際のLean解析の録画ではなく、操作を紹介するモック。
- 操作対象の座標はStageshowのdata-targetから測定。再生終了後は結果を表示したまま保持。
- 文字の切れ、一覧の空白、パネル着地時の揺れを自動点検と静止画で確認して修正。
- 自動点検のフレーム収集には一部27msを超える間隔があり、動作の連続性は完全には自動判定できていない。
- Chromiumヘッドレスで確認。実機のタッチ操作、Safari、Firefoxは未検証。
