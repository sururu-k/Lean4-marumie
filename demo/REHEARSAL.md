# 実画面の操作録画

動画は `Graph/Web/index.html` をChromiumで開き、実際に操作して作成する。別のグラフや簡略化した主張を重ねない。

- 画面サイズは1440×960と390×960。
- サンプルから `Examples.meet_comm` を検索し、中心に移動する。
- 実在する依存先 `Examples.meet` を選び、選択状態を検証する。
- レポートを開き、出力に中心の宣言が含まれることを検証して録画を終える。
- 撮影時はHTTP通信を遮断し、CDNなしで動作することも確認する。
- カーソルの移動先は実際のボタンの矩形から取得。カーソルだけは、Stageshowの矢印形を録画の補助として重ねる。
- Stageshowの「操作に原因を持たせる」「結果を読む時間を取る」「画面サイズごとに確認する」を適用。UI自体は本番のDOMであり、Stage上に作ったモックではないため、以前のモック向けfilm gateの結果は今回の検証として扱わない。
- `npm run record:demo` で再生成する。録画にViteサーバは不要。
- `npm run test:web` と `npm run test:web:states` で、表示、キーボード操作、空状態、不正な入力、大きなグラフ、長い名前、モーション軽減を確認する。

Chromiumヘッドレスで検証。実機のタッチ操作、Safari、Firefoxは未検証。
